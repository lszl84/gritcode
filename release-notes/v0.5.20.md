## What's new

**🪟 Side panels that respect your tiling layout.** On Hyprland, opening the session reference or the file editor in a tiled window no longer fights the compositor. gritcode shares the tile's space between the panels instead: the chat always keeps a comfortable width, the editor gets the rest, and closing a panel restores the previous layout. Floating windows still slide their panels out by growing, just like before.

**🤖 More automation hooks.** The local control interface gains `togglePanel` and `getPanes`, so scripts can open panels and read the layout of a running gritcode.
