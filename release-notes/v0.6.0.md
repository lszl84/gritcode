## What's new

**🧵 Threads.** A folder can now hold several conversations, all running at the same time. Start a new thread for an unrelated task and it begins with a clean context instead of the folder's whole history. Threads live in the left pane, and each one keeps its own draft. The session dropdown still picks the folder. A ● there means a thread finished while you were elsewhere, and a ⚠ means one failed.

**🤖 Subagents you can watch.** DeepSeek and Kilo models can now hand work to subagents that run in the background, and Claude Code's own subagents show up too. Each one appears under its parent thread with a live status line, and you can open it to follow along. Subagents read and research; edits stay with the parent.

**📝 A project brief for every new thread.** The first time you start a new thread in a folder, gritcode writes a short brief about the project with your selected model's provider. Every new thread starts with it, so it knows what the project is about from the first message.

**🔧 Fixes.** A bash command that times out now takes its child processes down with it, and Refresh in the file tree no longer saves the open file.
