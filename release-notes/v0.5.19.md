## What's new

**🎨 Omarchy theme integration.** On [Omarchy](https://omarchy.org), gritcode now takes its colors from your active theme: chat, tool calls, links, selections and editor syntax highlighting all follow it. Switch themes and gritcode recolors instantly, no restart needed. Colors are contrast-checked, so text stays readable on any theme. Everywhere else, the familiar built-in light and dark palettes stay as they were.

**🔤 Consistent code font.** The file editor now uses the same font size as code blocks in the chat, so the two always match, whatever your system font size.
